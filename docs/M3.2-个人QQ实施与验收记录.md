## 2. 新增功能说明

| 功能 | 说明 |
|---|---|
| 环境检测 | QQ 安装/运行、SnowLuma 安装（版本比对）/运行（按安装目录识别进程）、WebUI/OneBot 端口、OneBot `get_login_info` |
| 安装引导 | 未安装时给官方入口 + 3 步说明；**不代下载/解压/安装**；支持手动选择 SnowLuma 目录 |
| 启动引导 | 提示用户自行双击 `launcher.bat` 并在 WebUI 登录；**不代启动** |
| 适配插件 | 一键安装/修复/卸载 `dsh-qq-link@1.5.1`（npm 在线装，不打包） |
| 配置连接 | 从 SnowLuma `config/onebot*.json` **只读**取端点与令牌（账号级优先），写入适配插件；令牌只留主进程 |
| Harness 联通 | 读插件自述状态（`ok / 版本 / NapCat状态 / 活着的会话 / 绑定`），并在真实 Harness 上拿到证据 |
| 会话绑定 | 把某个 QQ 私聊绑定到指定 Harness 会话（合并写回，不覆盖已有绑定） |
| 人工验证 | "我已收到 QQ 回复"由用户点击记录，探测不自动置位 |
| 错误分类 | `harness-not-running / adapter-not-installed / bridge-route-missing / bridge-auth-required / backend-unreachable`，每条都带下一步 |

## 3. 技术架构与消息流转

```
QQ(手机/桌面)  ──扫码登录──▶  QQ NT (QQ.exe)
        ▲                        │ hook 注入（SnowLuma 自己做）
        │                        ▼
        │                 SnowLuma 2.4.0 运行时
        │             WebUI :5099  OneBot v11 HTTP :3000
        │                        ▲   │
        │        send_private_msg │   │ get_friend_msg_history（插件 2s 轮询）
        │                        │   ▼
        └───────────────── dsh-qq-link@1.5.1（Cordis 插件，运行在 Harness 进程内）
                                 │ ctx.agents / sessions
                                 ▼
                        Harness 0.2.0-rc.2 ──▶ DeepSeek API（M3.1 已验证）
```

* 本软件（DeepSeek Deploy Assistant）**只**做三件事：只读探测、写适配插件配置、读取插件自述状态；**不参与**消息转发。
* 令牌流向：SnowLuma `config/onebot*.json` →（只读）主进程 → `POST /dsh-qq-bridge/save` → 插件配置。**不进渲染层、不进日志、不进诊断包**。

## 6. 需要用户手动完成的操作（B-5 前置）

1. 安装桌面版 QQ（本机已有：`C:\Program Files\Tencent\QQNT\QQ.exe`）并**打开登录**（只能手机扫码）。
2. 从 **SnowLuma 官方 Releases** 下载 `SnowLuma-v2.4.0-win-x64.zip`，解压到固定目录（例如 `D:\SnowLuma`）。
   > 本软件不代下载；许可与 EULA 需你本人确认。
3. 双击 `launcher.bat` 启动；浏览器打开 `http://127.0.0.1:5099`，用启动窗口里的一次性初始密码登录。
4. 在 SnowLuma WebUI 里接入 QQ 进程、手机扫码登录，确认 **OneBot v11 HTTP 已开启（默认 3000）**。
5. 回到本软件「4. QQ 接入 → 个人 QQ」：选择 SnowLuma 目录 → 重新检测 → 安装适配插件 → 写入 OneBot 连接配置。
6. 在 Harness 页面里打开/新建一个会话，回到面板点「重新检测」，把会话 id 与自己的 QQ 号填入并「绑定私聊」。
7. 用**另一个 QQ 号**私聊该号：确认 Harness 会话出现新轮次、且 QQ 侧收到回复；然后点「我已收到 QQ 回复」记录验证。
