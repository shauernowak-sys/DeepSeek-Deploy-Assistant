## 0. 阅读说明

### 0.1 状态定义（本矩阵唯一口径）

| 状态 | 判定条件 |
|---|---|
| **已完成** | 有对应代码 + 自动化测试或实测证据，端到端可用 |
| **部分完成** | 有实现，但缺流程/界面/异常处理中的至少一项 |
| **未实现** | 没有实际功能实现 |
| **未验证** | 有实现，但缺少足够证据证明真实可用（仅单测或仅 Mock） |
| **待用户验收** | 必须由用户真实账号/设备/外部环境完成 |
| **已调整** | 有明确产品决策调整原始需求（R3/R4 等，见修订记录） |
| **不适用** | 有明确依据证明该需求不适用（如 V0.1 未启用远程清单） |

### 0.2 证据列写法

- **测试证据**：`tests/...`（本次审计实跑结果，见 §0.3）
- **实机证据**：`docs/evidence/...` 或 Mx 报告链接；`—` 表示无真实环境证据
- **UI 状态**：`可操作` / `只读展示` / `无入口` / `状态误导`
