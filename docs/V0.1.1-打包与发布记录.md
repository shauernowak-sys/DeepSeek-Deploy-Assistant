## 2. 与 V0.1 的差异

1. **插件资源 → 插件中心**：整理为「找插件 / 我的插件」两个入口。
2. **插件详情改为一屏**：点「查看详情」后直接看到**醒目的安装地址 + 复制按钮**，其余说明收进折叠区；
   步骤条 `1 找插件 / 2 看详情 / 3 确认安装` 三步可点击。
3. **安装地址可直接给 Harness**：npm 给精确版本、GitHub 给 `github:owner/repo`；粘贴到 Harness「插件 → 添加插件」即可。
   未通过评估的插件不显示假地址，只说明原因。
4. **我的插件**：读取本软件管理的 `web` 配置环境里实际安装的插件；四段证据（安装 / 加入配置 /
   已加载 / 配置已写入）分开显示，缺证据显示「未验证」并说明原因。
5. **打开设置**：只对核实过的入口开放——官方 QQ 插件与 Aurabot 打开 Harness 对应面板（先确保 Harness
   由本软件启动），个人 QQ 适配插件切到本软件面板。
6. **图文引导**：官方 QQ 扫码绑定、Aurabot 人设管理，使用隔离环境的真实运行截图，逐步说明「点哪里 / 看到什么算完成」；
   没有截图的步骤明确标注原因。
7. **卸载**：确认 → 备份 profile → 停 Harness → 官方 `plugin remove` → 重启；实测插件数据（人设/记忆）保留。
8. 修复：卸载前未停 Harness 导致失败、`ERR_PNPM_UNEXPECTED_STORE`、全新环境首次安装被配置自检误判失败、
   渲染层复制在窗口未聚焦时静默失败（改为主进程写剪贴板）。
9. Harness 基线为 `0.2.1-rc.3`（V0.1 包为 `0.2.0-rc.2` 时期）。

## 4. 本机 Harness 版本现状（2026-11-05 16:45 实测）

| 项 | 实测值 | 说明 |
|---|---|---|
| 代码基线 `BASELINE.dsh.version` | `0.2.1-rc.3` | `compat.json` 的 `C4-rc3` 为 `verified-local`（隔离环境装过、能启动并生成绑定入口） |
| 本软件受管 Harness | **只有 `harness\0.2.0-rc.2`**（2026-11-02 15:36 部署） | 没有 `harness\0.2.1-rc.3` 目录 |
| 系统 Harness（PATH 上的 `dsh`） | 未安装 | `Get-Command dsh` 为空 |
| 官方桌面版 Harness | 未安装 | `%LOCALAPPDATA%\Programs` 下只有本软件与 Node.js |
| 环境检测结果 | `dsh.installed=false`，`route=none` | Node `22.23.4`、pnpm `11.28.5` 已就绪，仅缺 Harness |
| 部署向导结论 | 「需要安装 Harness（本软件安装）：未检测到可复用的 Harness，将安装 **0.2.1-rc.3**」 | 这就是「部署环境版本和之前不一样」的原因 |
| 最近一次部署任务 | `state/tasks/full-deploy-0_2_0-rc_2.json`（2026-11-02，成功） | 那次装的是 `0.2.0-rc.2` |

**结论**：Harness 升级的是**代码基线**（0.2.0-rc.2 → 0.2.1-rc.3，见 [M4-Harness版本升级评估](./M4-Harness版本升级评估.md)），
但本机**从未按新基线重新部署**，所以受管目录仍是旧版；新版按设计会安装到 `harness\0.2.1-rc.3`，旧目录保留不删，
`dsh-home` 里的 profile 在修改前会先备份到 `state\backups`。要让本机真正跑在 0.2.1-rc.3 上，需要在部署向导里执行一次部署。

## 5. 安装与试用

1. 双击 `release/test-v0.1.1/DeepSeek-Deploy-Assistant-Test-V0.1.1-x64.exe`（按用户安装，不需要管理员权限）。
   本机已执行一次静默升级（`/S`），安装目录 `%LOCALAPPDATA%\Programs\DeepSeek Deploy Assistant`。
2. 启动 → 选择接入方式 → 部署向导：当前环境检测为「需要安装 Harness 0.2.1-rc.3」（旧 `0.2.0-rc.2` 目录保留）。
3. 部署完成后进入「插件资源」：
   - 「找插件」安装官方 QQ 机器人插件；
   - 「我的插件」打开它的设置页扫码绑定；
   - 个人 QQ 路线请先自行准备 SnowLuma，再在「个人 QQ」页配置。
