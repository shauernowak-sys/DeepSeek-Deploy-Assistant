## 5. 是否可以进入 M3

**可以进入 M3 的"能力补全"部分，但有 3 个必须先解决的阻塞项：**

1. **QQ-GATE-01**：需要真实 QQ 凭据与扫码设备，否则官方 QQ 路线永远无法对外。
2. **第二环境（Win11）**：需要一台干净 Win11 机器，否则"支持 Win11"只能继续标注待验证。
3. **API 真实连接测试**：PRD §11 的必需能力，当前缺失，属于 M3 首要补齐项。

建议 M3 顺序：`API 真实连接测试（K-M2-04）` → `QQ-GATE-01 实机` → `第二环境验证（K-M2-02）` → `插件资源库与国内三层下载` → `代码签名 S1`。
