## 2. 必须调整的技术决策（M0 结论驱动）

| # | 调整 | 理由（M0 证据） |
|---|---|---|
| D1 | **安装链路一律用 pnpm，禁止 npm** | M0 §3：npm 14 分钟挂起；pnpm 104 s 完成 |
| D2 | 只允许 **C1′**（dsh 0.2.0-rc.2），`compat.json` 内 `0.1.0-rc.8` 标 `blocked` | M0 §4：rc.8 `dsh web` 崩溃 3/3 |
| D3 | profile 固定 **`web`**，不用自定义名 | M0 F20：自定义 profile 不含 Web UI |
| D4 | 健康探测三级（存活/鉴权/可用），**401 只算存活** | M0 F22 + 任务约束六 |
| D5 | peer 缺失不判失败（profile `autoInstallPeers: false`） | M0 §6 |
| D6 | QQ 插件仅在线安装，不打包/不镜像 | M0 §10：connector `UNLICENSED` |
| D7 | 安装器不集成代码签名（`signAndEditExecutable: false`） | 本机非管理员，electron-builder 解压 winCodeSign 需符号链接权限 |
