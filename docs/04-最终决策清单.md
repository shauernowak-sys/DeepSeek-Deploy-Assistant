>

> - **阻塞开发**：不解决就无法进入对应阶段（标注阻塞的阶段）。

## 5. 一页速查：允许 / 不允许

| 场景 | 允许 | 不允许 |
|---|---|---|
| 用户只有 Desktop | 只读检测版本、展示 `profiles/desktop` 插件快照、打开官方入口 | 代下/代装安装包、写其 profile、把 CLI 插件"移"过去 |
| 用户只有 CLI | 用 `web` profile（0.1.x 下唯一带 Web UI）、装白名单插件、备份后重置 | 使用 `latest` 解析版本、用 `--from-default-profile` 当回滚、用自定义 profile 名期待 Web UI |
| 用户两者都有 | 强制选择页 + 记住选择 | 静默选一个、在一个任务里混装 |
| 个人 QQ | 官方入口 + 安装说明 + 装后检测 | 自动下载/打包任何第三方网关（含 NapCat、SnowLuma） |
| 离线包 | 只装许可清晰的依赖闭包；或"预热 pnpm store 后 `--offline`" | 打包 `UNLICENSED`/无 license 依赖；把腾讯 connector 放进镜像 |
| 版本 | 清单里的精确串（含 prerelease） | `^` 范围、`latest`/`alpha`/`next` |
| 健康探测 | `GET /` **401 视为在线** | 用 200 判定"服务未就绪" |
