## 1. D11 许可门禁

### 1.1 判定规则（代码化，不是文档约定）

实现在 [packages/core/src/market/license-gate.ts](../packages/core/src/market/license-gate.ts)：

| 阶段 | 行为 |
|---|---|
| 归一化 | `normalizeSpdx()`：别名表覆盖 `Apache 2.0`（带空格）、`Apache License, Version 2.0`、`Python 2.0`、`(from file)` 后缀等前置验证 §5.4 点名的漏判写法 |
| 判定 | `classifyLicense()` 三态：`allowed`（宽松列表）/ `needs-review`（未在列表内但未被禁止，如 MPL/LGPL，**默认阻断分发**）/ `denied`（`UNLICENSED`、`SEE LICENSE IN …`、`NOASSERTION`、未声明） |
| 表达式 | `MIT OR Apache-2.0` 拆项判定：任一 `denied` → 整体 `denied`；全部 `allowed` → `allowed` |
| 闭包裁决 | `evaluateClosure()`：逐包给出 `verdict` + `redistributable`，整体 `verdict` 取最差项 |
| 硬门禁 | `assertRedistributable()`：非 `allowed` 即抛 `DdaError(E_LICENSE_BLOCKED)`，消息**点名到包名+版本+许可**，hint 给出「改为在线安装」的处置 |
| 产物 | `renderThirdPartyNotices()` 输出声明片段；含 Apache-2.0 时自动附「须随附 NOTICE 与许可全文」提示 |

新增错误码 `E_LICENSE_BLOCKED` 并写进 `DIAGNOSTICS`（[packages/spec/src/errors.ts](../packages/spec/src/errors.ts)）。

### 1.2 CLI（替代 `scripts/license-check.mjs`）

```powershell
npm run license:check                                                     # = --scope=product（CI 用）
pnpm exec tsx scripts/license-gate.ts --scope=plugin:plg-official-qqbot --profile-dir=<profile>
pnpm exec tsx scripts/license-gate.ts --scope=all --profile-dir=<profile> --json=r.json --notices=NOTICES.md
```

- `--scope=plugin:<catalog id>` 会先校验 profile 里实际安装的版本与 catalog 宣称一致，避免「拿别的版本的闭包给该条目背书」。
- 退出码：0 = 全部 `allowed`；1 = 存在 `denied`/`needs-review`（即不可由我方分发）。

## 2. D01 索引构建链

### 2.1 两层文件与分工

| 层 | 产物 | 校验方 |
|---|---|---|
| L1 官方层 | `apps/desktop/resources/market/index.json` | 官方 `parseMarketIndex()` **+ 我方 6 类追加断言** |
| L2 overlay | `apps/desktop/resources/market/catalog.overlay.json` | `CatalogOverlaySchema`（zod，`.strict()`） |

字段分工以常量 `MARKET_FIELD_OWNERSHIP` 固化，并在每次构建时打印（见 §2.3 输出），避免后来者重复实现官方规则或把 overlay 字段塞进 `index.json`。

### 2.2 构建链

```
catalog/entries/*.ts（唯一事实来源，zod CatalogEntrySchema 强校验）
  ├─ catalog/data/official-qqbot-closure.ts（真实 37 包闭包许可快照）
  └─ catalog/icons/plg-official-qqbot.svg
        ↓ scripts/build-index.ts
  index.json + catalog.overlay.json + icons/
        ↓
  ① zod（catalog / overlay）
  ② 官方 parseMarketIndex(index.json, baseUrl)
  ③ 我方断言：engines 锁定 =compat.dsh、compat 必须 verified-local、条目版本与 compat.qqbot 一致、
     闭包裁决与 license.redistributable 一致、图标存在/类型/≤32 KiB/边长≤256、
     overlay 字段不得出现在 index.json、图标相对引用解析正确、registry publishTimestamp/integrity 一致
        ↓ scripts/validate-index.ts（只校验既有产物，能发现「catalog 改了但产物没重建」）
```

`apps/desktop/resources` 已由 `electron-builder.yml` 的 `extraResources` 打进安装包，因此索引随包内置（满足 PRD CN-7「索引可达性」，断网也不空白）。

### 2.3 构建实际输出（2026-11-04）

```
[build-index] index.json: 1 个插件 / 1 个版本 · overlay: 1 条 · 图标: 1 个
[build-index] 输出目录: ...\apps\desktop\resources\market
[build-index] 校验基址: https://market.invalid/dda/v1/index.json
字段分工（官方库负责的规则不得在本仓库重复实现）：
  官方校验器：
    - format === 1
    - title / description 必须含 en
    - plugins[].name 的 npm 包名语法与长度
    - versions[].version 精确 SemVer、去重、降序
    - versions[].publishTimestamp 整数范围
    - versions[].source 的 npm/git 形态与 URL 规范性
    - versions[].engines.dsh 的 SemVer range 语法
    - icon 的 data URL 类型/32 KiB 上限/相对引用解析
    - metadata.categories/labels/sortKeys 的声明-引用一致性
  我方 overlay：
    - license（SPDX + redistributable）
    - integrity（sha512，与 registry dist.integrity 一致）
    - depsClosure（D11 计算出的逐包裁决）
    - acceptance（可执行验收项）

    - zh（中文名称/用途/风险）
    - safety（外联、权限、是否需重启）
    - installNotes
    - status（verified / needs-review / blocked）
[build-index] OK（官方校验器 + 我方断言全部通过）
```

registry 复核实测值：

| 字段 | 值 | 来源 |
|---|---|---|
| `publishTimestamp` | `1793375955`（2026-10-30T15:59:15.778Z） | `npm view @tencent-connect/dsh-qqbot time` |
| `integrity` | `sha512-E15Du9xW…hmu9Lz+IA==` | `npm view @tencent-connect/dsh-qqbot@0.5.5 dist.integrity` |
| 校验基址 | `https://market.invalid/dda/v1/index.json` | 仅用于解析相对图标（`.invalid` 保证不会被误请求） |

### 2.4 D01 测试（`tests/core/market-index.test.ts`，16 例）

| 计划要求 | 用例 |
|---|---|
| ① 合法索引通过 | 「合法 catalog 产出的 index.json 能通过 parseMarketIndex，且逐字段与 catalog 一致」 |
| ② 删除 `publishTimestamp` → 失败且路径为 `$.plugins[0].versions[0].publishTimestamp` | 同名用例（断言 `MarketIndexError.path`） |
| ③ `version='latest'` → 失败 | 「版本写成 latest → 官方校验器拒绝」 |
| ④ 图标 32769 B → 失败 | 「图标超过 32 KiB 或缺失 → 构建期断言失败」 |
| ⑤ 纯中文 `title` → 失败（`must contain en`） | 「纯中文 title → 官方校验器拒绝」 |
| ⑥ overlay 缺 `license` → 失败 | 「overlay 缺少 license → zod 校验失败」 |
| ⑦ 生成物与 `parseMarketIndex` 返回值逐字段一致 | ①（`collectIndexProblems` 返回空）+「把 overlay 字段塞进 index.json → 官方校验器静默丢弃，我方断言必须报错」 |
| 计划外补充 | engines 未锁定、compat 非 verified-local、`redistributable` 与闭包结论不一致、blocked 条目不得出现在索引、英文标题不得含中文、artifact 存在性、registry 三项不一致 |
