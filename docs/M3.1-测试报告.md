## 3. 真实端点测试（本轮实跑，使用**无效** Key）

| 场景 | 结果 | 关键数据 |
|---|---|---|
| `https://api.deepseek.com/anthropic` + `deepseek-flash` + 无效 Key | **verdict=auth，HTTP 401** | 112–184 ms；步骤 `address:ok → dns:ok → request:ok → auth:fail`；提示"密钥无效或已失效（HTTP 401）" |
| `https://nonexistent-model-host.invalid/v1` | **verdict=network** | 336–506 ms；步骤 `address:ok → dns:ok → request:fail` |

意义：证明连接测试**确实打到真实端点**，不是本地假校验；且 401 被正确归类为鉴权失败而非"连接成功"。

> 说明：本机 DNS 对保留域名返回了合成地址，因此该用例落到 `network` 而非 `dns`；`dns` 分支由单测用注入的 `ENOTFOUND` 覆盖。
