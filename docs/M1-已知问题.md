## 安全相关自查（本轮）

| 检查 | 结果 |
|---|---|
| 是否使用 `shell: true` | 否；仅 `spawn(exe, args[], shell:false)` |
| 是否允许任意命令 | 否；白名单 `node.exe` / `reg.exe`，参数拒绝 shell 元字符 |
| 是否明文存密钥 | 否；`safeStorage`(DPAPI) + 仅回传掩码 |
| 是否把密钥写日志 | 否；`redact()` 覆盖 `sk-*`/appSecret/QQBOT_SECRET（单测覆盖） |
| 渲染进程权限 | `contextIsolation`+`sandbox`+`nodeIntegration:false`；CSP `default-src 'self'`；禁止新窗口 |
| 解压安全 | zip-slip/符号链接/超量均有单测 |
| 是否修改系统级配置 | 否；仅 HKCU 卸载项（安装器自身）、私有目录、子进程 PATH |
| 是否删除用户数据 | 卸载默认保留（已实测）；回滚只删本次创建 |
