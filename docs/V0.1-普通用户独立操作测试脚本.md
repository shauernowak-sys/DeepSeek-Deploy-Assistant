# V0.1 普通用户独立操作测试脚本（待执行）

目的：观察无编程经验用户能否独立完成操作，不由观察员解释界面。使用独立 Windows 测试环境，测试前确认账号、密钥和网络由参与者自行提供。不得记录密钥、QQ 凭据或私人消息。

1. 打开应用，说明你认为软件能做什么，以及下一步是什么。
2. 检查环境，理解提示；查看部署方案，说明将安装、复用和修改的内容后自行决定是否确认。
3. 部署中观察当前步骤；按测试人员指示暂停并继续，确认已完成步骤没有重复。
4. 根据界面配置自己的模型并测试连接；记录实际结果，不把保存配置等同于连接成功。
5. 按所需路线完成官方 QQ 或个人 QQ 引导；个人 QQ 的 SnowLuma 由用户从官方入口自行下载、安装和登录。
6. 打开助手并复制一条预制提示词；查看故障诊断入口。
7. 如果条件允许，关闭并重新打开应用，寻找继续任务的入口。
8. 记录每一步是否独立完成、耗时、卡点、错误原文（脱敏）以及观察员是否提供帮助。

真实 QQ 消息由用户本人验证并记录结果。三位无编程经验用户独立测试均完成并经产品方判定后才可判断 A14；此脚本本身不代表通过。
