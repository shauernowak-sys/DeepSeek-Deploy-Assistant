# M4 D02 插件资源中心第二轮实施报告

**日期：** 2026-11-05
**范围：** 在 D02 已有资源中心基础上，补充 QQ 生态调研、分类与推荐搭配、候选状态说明、安装来源/进度、Aurabot 图文引导。
**基线：** DSH `0.2.0-rc.2` / qqbot `0.5.5` / `web` profile（未修改冻结 PRD 与锁定版本）。

---

## 1. 本轮结论

1. 资源中心现在能展示 **1 个可安装条目 + 13 个候选条目**，并按「已验证 / 待验证 / 暂不可安装」分区；候选一律不渲染安装按钮。
2. 新增 **QQ 接入、人设与陪伴、记忆、语音、图片与表情包、主动消息与 QQ 空间** 六个分类，以及按官方 QQ / 个人 QQ 路线切换的「推荐搭配」。
3. 每个条目至少展示：名称、用途、功能标签、作者、来源、版本、公开关注度、适用路线、当前状态、外部组件、详情/来源/使用引导入口。
4. 安装确认页展示版本、来源、安装位置、空间信息、权限和下载来源策略；安装过程中通过主进程真实步骤事件显示当前步骤与来源，不再伪造百分比。
5. 为 Aurabot 增加 6 步使用引导，并明确标注 **「设计示意 · 非实机截图」**；官方 QQ 条目使用已核实的验收步骤，也明确说明没有实机截图。
6. 本轮没有新的插件被开放安装：唯一安装按钮仍只属于已通过策展与既有安装证据的官方 QQ 插件。其余项目保持待验证或暂不可安装。

> 「推荐搭配」只是建议，不是强制组合；插件最终选择权在用户。

## 2. 调研方法与边界

- 取数日期：**2026-11-05**。
- 公开关注度：GitHub 仓库 `stargazers_count`。**星标只表示公开关注度，不是真实用户量、安装量或使用量。**
- 版本与提交：npm registry `dist-tags.latest` 或 GitHub 仓库 `package.json` + 最新相关提交。
- 许可：项目 `package.json`、`LICENSE` / 许可文件；对 GitHub 项目额外核对了当前版本与历史版本的差异。
- 兼容性：只采信项目自己声明的 `dsh.compatibility`、README 的验证基线，以及本产品既有实测记录；不以「功能完整」「关注度高」推断兼容。
- 安装证据：本机当前**没有部署 Harness**，因此本轮没有对新增项目执行真实安装或 QQ 收发。无法取得证据的项目全部保持待验证/暂不可安装。

### 2.1 明确区分项目形态

| 形态 | 含义 | 本轮例子 |
|---|---|---|
| `plugin` | 有 `dsh.bundle.patch`，可作为 Harness 插件挂载 | 官方 QQ 插件、Aurabot、dsh-meme、dafeiyu、qq-link |
| `bridge` | 独立运行的桥接程序，不是 Harness 插件 | qq-bridge |
| `tool` | 给会话补工具能力的插件，通常依赖某个 QQ 网关 | dsh-qq-tools |
| `reference` | 数据包/参考项目，不能当插件挂载 | dsh-plugin-catalog |

## 4. 关键事实与兼容性判断

### 4.1 官方 QQ 插件

- 来源：`https://github.com/tencent-connect/dsh-qqbot`；npm `@tencent-connect/dsh-qqbot@0.5.5`。
- `package.json` 明确声明 `dsh.client.platform: "web"`，`dsh.compatibility.dshReleases` 含 `0.2.0-rc.2: compatible`。
- 许可：插件本体 MIT，但闭包含 UNLICENSED 的 `qqbot-connector@1.2.0`，因此 **只能在线安装，不得离线打包、镜像或重分发**。
- 权限：加载后向腾讯 QQ 开放平台发起绑定/鉴权；需要手机 QQ 扫码或 AppID/AppSecret；会读取被授权群/私聊的消息。
- 本轮无 VPN/代理下载实测：
  - 镜像 `registry.npmmirror.com`：HTTP 200，225,458 字节，386 ms；
  - 官方 `registry.npmjs.org`：HTTP 200，225,458 字节，910 ms；
  - 两者 SHA-512 均为 `sha512-E15Du9xWfWk7CffRba8/ADHV9l6t9kDQ+U3ImLmB5Ffpnbwsm5ovYtHlhiENlILaqx0r+46cSxBiqhmu9Lz+IA==`，与 catalog 记录一致。
  - 测试时环境存在 `HTTP(S)_PROXY=http://127.0.0.1:7990`，下载命令显式使用 `curl --noproxy '*'` 绕过代理，属于无代理直连测试。
  - 这只是**下载与完整性**证据，不等于本机完整安装或 QQ 收发成功。

### 4.2 Aurabot

- 仓库当前规范地址为 `aureth-labs/dsh-aurabot-qq`，但 `package.json` 的 repository 与 README 安装命令仍写 `accomplish07zrh-eng/dsh-aurabot-qq`（旧组织名）。本轮按具体提交记录，不把旧地址当作永久可用的下载源。
- `private: true`，npm 上没有 `dsh-aurabot-qq` 包；只能通过 GitHub 源安装。
- 代码 MIT；README 明确角色素材为 CC BY-NC-SA 4.0，且 50 MB+ 素材由插件首次启动时从独立素材仓库另行下载，不随本仓库分发。
- README 描述它可以启停用户已安装的 SnowLuma，但不会下载 SnowLuma、不会替用户同意 EULA；这与「SnowLuma 由用户自行下载、安装、启动」的边界一致。但**本轮没有在锁定宿主上验证其实际行为，因此不启用**。
- 未声明 `dsh.compatibility`，README 也没有 `0.2.0-rc.2` 的验证记录。

### 4.3 qq-bridge 的版本与许可

- 当前 `v0.2.1-r2`（提交 `b77e4a26a730d10a8c45982eadce554bd1f0a969`）使用 **PolyForm Noncommercial 1.0.0**，禁止商业用途。
- `v0.2.1-r1` 的 `package.json` 仍为 `MIT`；更早版本沿用当时的 MIT。必须按具体版本核实，不能把「历史版本 MIT」套到当前版本。
- npm 上的 `qq-bridge` 历史版本（`1.1.0`–`1.1.5`）已于 2026-10-27 全部撤回，当前只能从 GitHub 获取。
- 项目是独立桥接程序，不是 DSH 插件；安装会执行 `postinstall` 修补本机 `@snowluma/sdk`，并读取本机 OneBot 配置与令牌。

### 4.4 dsh-dafeiyu-dot

- README 与 `docs/verification.json` 均以 **DSH `0.2.1-rc.3`** 为验证基线，与本产品锁定的 `0.2.0-rc.2` 不同；`package.json` 未声明 `dsh.compatibility`。
- 因此本轮判为 `host-version-incompatible`，不自动视为兼容，也不因为功能覆盖人设、记忆、语音、QQ 空间就直接启用。

### 4.5 dsh-meme / dsh-qq-tools / dsh-qq-link

- `dsh-meme@0.1.77`：npm 包可追溯，解包约 4.4 MB，核心无第三方运行依赖；`sharp` 为可选原生依赖。未声明 `dsh.compatibility`。
- `dsh-qq-tools@0.10.2`：npm 包可追溯，解包约 0.2 MB；只支持 SnowLuma，NapCat 等 OneBot 实现不支持；`package.json` 只写 `dsh: "0.2.x"` 范围。
- `dsh-qq-link@1.5.1`：自定义许可允许安装、修改和商用，但再分发必须保留署名、说明改动并沿用同许可；只声明兼容 `0.2.1-rc.3`。

## 5. 产品与界面变化

### 5.1 分类

新增并展示：

- QQ 接入
- 人设与陪伴
- 记忆
- 语音
- 图片与表情包
- 主动消息与 QQ 空间

原有「界面小组件 / 开发工具 / 插件市场」仍保留，避免已有候选无分类可归。

### 5.2 推荐搭配

- **官方 QQ**：官方 QQ 机器人（可安装）→ 表情包插件（待验证，可选）。明确说明官方路线目前没有已验证的人设/记忆/语音插件，不强行凑搭配。
- **个人 QQ**：SnowLuma（外部组件，用户自行准备）→ Aurabot（待验证）→ dsh-qq-tools（待验证，可选）→ dsh-meme（待验证，可选）。
- 明确提示：Aurabot、qq-bridge、dsh-qq-link 是互相替代的 QQ 通道，只选一个；dsh-qq-tools 只补工具，不负责接入。
- 「最终选择权在你」，可以只选一个，也可以不装。

### 5.3 条目与详情

每个条目显示名称、用途、功能标签、作者、来源、版本、GitHub 星标与查询日期、项目形态、适用路线、当前状态、外部组件、详情/来源/使用引导入口。

详情页额外显示：

- 暂不可安装时的完整拒绝理由（受控 `code` 中文解释 + 具体 `detail`）；
- 兼容性出处、体积说明、安装方式；
- Windows x64 / 锁定宿主 `0.2.0-rc.2` / `web` profile 的支持等级（已验证 / 已声明未实测 / 未验证 / 不兼容），并附说明；
- 外部组件、已知冲突；
- 联网与权限、许可与分发限制；
- 六段证据：策展 / 下载 / 安装 / 加载 / 配置 / 连接；缺证据一律「未验证」；
- 「已安装 ≠ 已加载 ≠ 已配置 ≠ QQ 已连接」的明确提示。

### 5.4 安装确认与真实进度

- 确认页展示具体版本、安装位置（`<dataDir>\dsh-home\profiles\web`）、空间说明、权限、风险。
- 下载来源说明：**本产品没有自建国内资源库**；安装时先尝试 `npmmirror`，失败后按既有策略切换官方 `npmjs`；实际来源显示在进度里。
- 新增主进程 → 渲染层进度事件 `market:install-progress`：
  - 阶段：`starting` / `step` / `source` / `done` / `failed`；
  - 步骤来自 9 步安装编排的真实执行，不伪造百分比；
  - 来源来自真实的镜像/官方尝试，不在未尝试时宣称可达；
  - 事件不携带命令输出、令牌或聊天内容。
- 失败时展示可读原因与下一步，并保留「重试安装」入口；成功后明确提示还需要重启、扫码授权和真实测试消息。

### 5.5 Aurabot 图文引导

- 6 步，一屏一件事：打开插件设置页 → 连接 SnowLuma → 新建/修改/切换人设 → 管理记忆/表情/语音 → 按需开启主动消息和 QQ 空间 → 发送测试消息判断是否生效。
- 每步包含「在哪里操作」「怎么判断生效」和一个编号设计示意面板。
- 页面顶部与徽标均标注 **「设计示意 · 非实机截图」**；说明 Aurabot 尚未在本产品通过安装验证，也没有真实界面截图。
- 官方 QQ 引导使用已通过的验收步骤，并标注「已核实步骤 · 无实机截图」。

## 6. 安全与冲突处理

- 同一 QQ 号/会话被多个通道同时处理：在推荐搭配和条目详情中提示「只选一个」，不自动叠加两条聊天通道。
- 主动消息/空间发布：说明默认关闭、发布前确认可见范围与内容；本产品不替用户开启。
- 不读取、记录或上传完整密钥、QQ 聊天内容和隐私数据；进度事件只包含步骤名、状态和来源标签。
- 候选一律没有安装按钮；`status !== 'verified'` 由组件测试覆盖。
- 安装服务仍只接受 `plg-official-qqbot`，不会把候选名称传给安装器。
