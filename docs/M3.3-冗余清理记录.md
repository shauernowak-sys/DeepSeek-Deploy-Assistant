## 3. 删除的符号与接口（0 个文件）

### 3.1 无效 IPC / preload / service 方法

| 删除项 | 原因 |
|---|---|
| IPC `personal:consent` + `PersonalQqService.setConsent()` | 旧流程"本软件代用户记录 EULA 接受"；现在协议由用户本人在 SnowLuma WebUI 勾选，**无人调用** |
| IPC `personal:remove-adapter` + `PersonalQqService.removeAdapter()` | 界面上没有卸载适配插件的入口，**无人调用**（适配插件仍可通过"安装/修复"覆盖） |
| IPC `personal:save-settings` + preload `personalSaveSettings` | 界面不再保存端口等手动设置（端口只从清单/自动发现来），**无人调用** |

### 3.2 无效 Schema / 常量

| `PersonalQqDetectSchema` | 旧"探测接口"遗留，从未注册 |
| `PersonalQqEmptySchema` | 被 `SnowLumaEmptySchema` 取代，从未使用 |
| `PersonalQqSettingsSaveSchema` | 随 save-settings IPC 一起失效 |
| `SNOWLUMA_STEP_ID_SET` | 未使用（校验走 zod enum） |

### 3.3 无调用方的函数（core）

| 删除项 | 原因 |
|---|---|
| `looksLikeSnowLumaDir()`（locate） | 从未被引用；下钻逻辑内联在 `verifyInstallDir` |

| `listDirNames()`（install） | 从未被调用 |
| `waitForOneBot()`（health） | 从未被调用（运行时只做单次 `checkOneBot`） |

### 3.4 渲染层重复类型（12 个 → 0）

`PersonalQqPanel.tsx` 里手写的 `Evidence / PersonalStatus / Guide / PersonalSettings / StepStatus / DeployStep / DeploySnapshot / ProcessInfo / ConfigInspection / InstallCheck / InstallVerification / InstallDiscovery` 全部删除，改为从 `@dda/spec` 导入（`type`-only，构建时擦除，不会把 zod 打进渲染层）。

为此把 4 组跨进程契约收敛到 `@dda/spec`（唯一来源）：

- `InstallCheck` / `InstallVerification` / `LocateCandidate` / `SnowLumaInstallDiscovery`（原在 core）
- `SnowLumaProcessStatus`（原在 core/process.ts）
- `SnowLumaConfigHttpServer` / `SnowLumaConfigInspection`（原在 core/config.ts）
- `PersonalQqGuide`（原为 service 的内联返回类型）

### 3.5 降级为模块私有的导出（20 个）

只在本文件内部使用的类型/常量不再对外导出，缩小公共 API 面：
`EnsureConfigOptions/EnsureConfigResult`、`DeployQqState/LinkState/SnowLumaLinkDeps/StepOutcome`、`EnsurePackageOptions/EnsurePackageResult`、`WaitResult/OneBotHealth`、`InstallOptions/InstallResult`、`DiscoverOptions`、`SpawnedChild/SpawnDeps/StartOptions`、`SNOWLUMA_REPO/SNOWLUMA_API_BASE/ResolveReleaseOptions`、`UninstallOptions`；以及 `createEmptySteps`、`GATED_STEPS`、`sumUncompressedSize`、`USER_DATA_DIRS`、`PackageValidation`、`ExistingInstall`、`resolvePackageRoot`、`resolveInstallEntries`、`defaultOneBotConfig`、`ONEBOT_CONFIG_FILE`、`CONFIG_DIR_NAME`。

### 3.6 其他

- `SnowLumaDeploymentService.configBackups()` 里的 `const installDir = …; void installDir;` 死代码。
- `PersonalQqService.discoverInstallDir()` 里**第二套**常见目录候选清单（与新 `locate.discoverInstallDirs` 重复）→ 改为调用同一实现。
