## 1. 实现（[packages/core/src/market/local-import.ts](../packages/core/src/market/local-import.ts)）

```
prepareLocalImport({ sourcePath, entry, outDir, expectedSha256?, packDirectory })
  ① assertLocalImportAllowed(entry)      ← 许可门禁（在任何文件操作之前）
  ② inspect（目录 / tgz / zip）           ← tgz 走自带 ustar 解析；zip 复用 extractZip（含 zip-slip 防护）
  ③ validateImportedPackage(pkg, entry)   ← name/version/bundle patch/生命周期脚本
  ④ 产出绝对路径 tgz（zip/目录经 pnpm pack）
  ⑤ 校验打包结果真的包含 bundle patch     ← 复现并拦住 "files 漏配" 的坑
  ⑥ SHA-256（可选与期望值比对）
```

要点：

- **tgz 读取不引入新依赖**：`listTarballEntries()` / `readTarballFile()` 直接解析 ustar（含 `prefix` 字段），
  全部条目先过 `assertSafeEntryPath()`——与 zip 相同的路径穿越防护。
- **失败不留半成品**：目录/zip 导入中途失败会删除本次生成的 tgz；tgz 输入永不删除用户文件。
- **未提供期望哈希时**：返回 `hashChecked=false` 并给出明确 warning（"仅限用户自备包"），不假装校验过。

## 2. 打包适配器（[packages/adapters/src/pkgmgr/pack.ts](../packages/adapters/src/pkgmgr/pack.ts)）

- 调用 `node <pnpm.cjs> pack --pack-destination <outDir> --config.ignore-scripts=true`
  （pnpm 11 不认 `--ignore-scripts`，必须写成 config 形式，已实测）。
- 只信 pnpm 报告的产物路径，不猜文件名；退出码非 0 时把 stderr 尾部带进错误。
- 为什么用 pnpm pack 而不是手写 tar：它尊重 `files` 白名单，产物结构与 registry tarball 一致。

## 3. 许可与分发边界

| 输入 | 结果 |
|---|---|
| 官方 QQ 插件条目（`redistributable=false`，闭包含 `UNLICENSED`） | `E_DISTRIBUTION_BLOCKED`，消息点名 `@tencent-connect/qqbot-connector@1.2.0`，并指向"改为在线安装" |
| 闭包全允许的条目 | 可导入 |
| `status=blocked` 的条目 | 一律拒绝 |

这条门禁与 `QQ_PLUGIN_DISTRIBUTION`（安装侧的在线安装限制）合起来，正好覆盖 CN-5 的两端：
**在线安装允许、我方分发禁止**。本地导入不再是一个绕过口。

## 4. 验收对照

| 原始验收标准 | 证据 |
|---|---|
| 三种格式均安装成功 | 目录/zip/tgz 三条路径在单测中产出绝对路径 tgz；产物用真实 pnpm 安装验证：`pnpm add <abs>.tgz` → `+ dda-fixture-plugin 1.2.3`（2026-11-04 实测） |
| 非法包给出可读错误 | 缺 `package.json`、包名/版本不符、缺 `dsh.bundle.patch`、含生命周期脚本、打包缺 patch 文件——各有中文错误与处置建议 |
| 目录导入先打包 `.tgz` 再交给 pnpm | `packDirectoryToTgz`（pnpm pack），测试断言命令与绝对路径 |
| 哈希不一致即拒 | `E_HASH_MISMATCH`，且本次生成的 tgz 被删除（单测断言文件不存在） |
| zip-slip 防护覆盖 tar | 单测构造 `../evil.txt` 条目 → `E_EXTRACT_UNSAFE_PATH` |

> 说明：catalog 目前只有官方 QQ 插件这一个条目，而它被许可门禁拒绝，因此**没有**"真实插件走导入安装"的端到端记录；
> 这是产品决策（Gate 4 ②）的结果，不是遗漏。第一个允许再分发的条目出现时，`prepareLocalImport` 的产物可直接交给
> `dsh plugin add <abs tgz>`。
